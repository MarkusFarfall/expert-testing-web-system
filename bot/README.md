# Телеграм-бот «Пульт КТПП»

Личный бот платформы: результаты тестов, контроль сервера и напоминания об оплате ВДС.
Работает на ВДС отдельной службой `ktpp-bot` (systemd), данные — в SQLite, наружу ничего не открывает
(сам стучится в Телеграм и в API портала). Бот: **@Vdschecksbot** — «Экспертиза КТПП — пульт», со своей аватаркой.

## Что умеет
- **Результаты тестов.** Как только эксперт завершает тест — карточка: кто, какой тест, сколько процентов, когда.
- **Контроль сервера.** Два сбоя API подряд → предупреждение; восстановление → сообщение с временем простоя;
  перезапуск контейнера сторожем (`/var/log/vds/watchdog.log`) тоже с пометкой.
- **Напоминания об оплате ВДС.** В разделе «💳 Оплата ВДС» задаётся дата последней оплаты и срок (1/3/6/12 месяцев
  или свой) — бот считает дату следующего платежа и пишет за 7, 3 и 1 день, в день оплаты и при просрочке
  (каждые 3 дня), в 10:00 по Калининграду.
- **Статистика и итоги дня** (итоги — в 21:00, если были тесты).

## Доступ: по @юзернейму
Первый, кто напишет `/start`, становится **владельцем** (id запоминается). Остальным бот закрыт.

Владелец выдаёт доступ по юзернейму — **id не нужен**, человек может зайти с телефона, планшета и даже
сменить аккаунт: запись привязана к имени, id подставляется автоматически при первом входе.

- `👥 Доступ к боту` (кнопка в меню владельца) — список доверенных, их заявки и переключатели;
- `/allow @username` — добавить доверенного (видит меню, статистику, результаты, оплату);
- `/allow @username notify` — добавить и присылать ему уведомления (тесты, сервер, оплата);
- `/deny @username` — закрыть доступ;
- заявка: незнакомец пишет `/start` → владельцу приходит сообщение с кнопками «✅ Разрешить» / «⛔️ Отклонить»;
- в панели: 🔔/🔕 — переключить уведомления человеку, ✖️ — закрыть доступ;
- `OWNER_CODE` в `bot.env` — резервный вход в владельцы (`/start <код>`), если владелец потеряет аккаунт.

Уведомления приходят владельцу и тем доверенным, у кого включён 🔔.

## Файлы
- `bot.py` — весь бот (только стандартная библиотека Python).
- `bot-avatar.jpg` — аватарка бота; при каждом запуске бот сам проверяет её и обновляет (`setMyProfilePhoto`).
- `deploy-bot.sh` — обновление на ВДС.
- Секреты (`bot.env`: токен бота, пароль портала) живут **только на сервере** в `/root/ktpp-bot/bot.env` (chmod 600) — в репозиторий не попадают.

## Проверка и запуск
```bash
python3 bot.py --selftest     # 50 проверок логики без Телеграма (включая доступ по юзернейму)
python3 bot.py --check-api    # связь с Телеграмом и API портала
SSHPASS='…' ./deploy-bot.sh   # обновить код на сервере
```
Служба: `systemctl status ktpp-bot`, журнал: `/var/log/vds/bot.log` (ротация 5 МБ × 3).

Прогнать самопроверку на сервере, не трогая боевого бота:
```bash
ssh root@212.193.5.193 'cd /root/ktpp-bot && python3 - <<PY
import bot
bot.BASE_DIR = "/tmp/bottest"
raise SystemExit(bot.selftest())
PY'
```

Команды: `/menu`, `/pay`, `/stats`, `/results`, `/access`, `/id`, `/help`.
